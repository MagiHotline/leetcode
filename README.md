## Utilities

You can automatically scaffold a new problem folder and update `README.md` using the Python helper script:

```bash
python3 scripts/new_problem.py --id 1 --title "Two Sum" --difficulty Easy --topics "Array, Hash Table"
```

Or run in **interactive mode**:

```bash
python3 scripts/new_problem.py
```

### Manual README & Chart Update

To regenerate the `README.md` statistics, problem table, and the SVG radar chart at any time, run:

```bash
python3 scripts/update_readme.py
```

### 🎯 Updating Your Skill Points

Edit [`skills.json`](skills.json) manually to adjust your points / categories (scale 0-100):

```json
{
  "max_score": 100,
  "skills": [
    { "name": "Arrays & Strings", "score": 80 },
    { "name": "Trees & Graphs", "score": 65 },
    { "name": "Dynamic Programming", "score": 45 },
```

Then run `python3 scripts/update_readme.py` (or simply git push—the GitHub Action will update it automatically!).
